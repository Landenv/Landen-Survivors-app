# Landen Survivors — Android

Готовая сборка игры **Landen Survivors** для Android: фэнтези-выживалка в 3D с аркадным режимом и мультиплеером по Wi-Fi и Bluetooth.

Исходный код игры: [Landenv/Landen-Survivors](https://github.com/Landenv/Landen-Survivors).

## Что нового (сборка от 29.10.2026, седьмая)

- Герои держат оружие кистью: пальцы сжаты на рукояти, булава, щит и меч стоят по руке.
- Друид больше не проваливается в землю, анимация бега не сбивается при атаке на ходу.
- Монстры аркады не застревают за стенами, над ними видна полоска здоровья.
- Боссы втрое крепче и бьют сильнее.
- Урон всех героев выровнен.
- Игра работает в любом положении телефона: стоя и боком, а также на планшете — без прокрутки.

### Шестая сборка

- Друид с серпами, оружие у всех героев, кнопка «Поддержать», категория 12+.

### Пятая сборка

- Новые модели героев: воин-принцесса, рыцарь-паладин, боевой маг, ассасин, некромант и всадник-монах.
- 18 разных боссов, ни один не повторяется.

### Прошлая сборка

- Герои правильно держат оружие, оружие не бьёт впустую без врагов, ауры видны.
- Комната босса открывается только после зачистки всех комнат.
- Меню помещаются на экран телефона, интерфейс не прячется под вырез камеры.

## Установка

1. Скачайте [LandenSurvivors.apk](LandenSurvivors.apk) на телефон (кнопка **Download raw file** на странице файла).
2. Откройте файл и разрешите установку из этого источника, если Android спросит.
3. Запустите **Landen Survivors** — при первом запуске игра попросит придумать имя героя.

Нужен Android 6.0 или новее. Размер — около 21 МБ.

Это отладочная (debug) сборка: она подписана тестовым ключом, поэтому для Google Play не подходит. Если раньше была установлена сборка с другой подписью, сначала удалите её.

## Мультиплеер

- **Wi-Fi:** телефоны в одной сети Wi-Fi (или друзья подключаются к точке доступа хоста). Один игрок нажимает «Мультиплеер → Создать игру», остальные видят игру в списке.
- **Bluetooth:** сначала сопрягите телефоны в настройках Android. На вкладке Bluetooth хост создаёт игру, остальные выбирают его телефон из списка.
