# Landen Survivors — Android и Windows

Автор и разработчик — **Landen**.

Готовые сборки игры **Landen Survivors** для Android и Windows: фэнтези-выживалка в 3D с аркадным режимом и мультиплеером по Wi-Fi и Bluetooth.

Исходный код игры: [Landenv/Landen-Survivors](https://github.com/Landenv/Landen-Survivors).

## Что нового (сборка от 30.10.2026)

- Новый монах: своя модель автора с новым скелетом и анимациями, копьё крепко держит в кулаке.

### Шестая сборка 30.10

- Карточки испытаний: у каждого испытания своя вкладка с вращающейся 3D-моделью босса, описанием его приёмов и выбором сложности.
- В «Авторах» указан автор и разработчик игры.

### Пятая сборка 30.10

- **Версия для Windows:** установщик и портативный exe. Мультиплеер по Wi-Fi вместе с телефонами: ПК видит игры телефонов, телефоны — игры ПК.
- Исправлено: друг с надетым комплектом мог не войти в мультиплеерную игру.
- Инвентарь на 255 вещей, вкладки по типу вещи и фильтр по характеристике.
- Вещь можно заблокировать замком, чтобы случайно не продать.
- Вещь, надетую на одного героя, другой не наденет, пока её не снимут.
- Иконки надетых вещей во всех слотах одного размера.

### Четвёртая сборка 30.10

- Лечебные зелья по кнопке: в выживании до 3 (по одному за каждого босса), в испытаниях 3 / 2 / 1 по сложности.
- В испытаниях основная атака ручная — крупная кнопка атаки. Камера стоит за героем под постоянным углом, двигаться и уворачиваться стало свободнее.
- Выживание не кончается после 24-й волны: волны усиливаются, боссы возвращаются кругами.
- Монах снова с копьём. Летящее оружие у каждого класса своё: топор, бумеранг, серп ци.
- У приёмов боссов видна картинка удара: падающие глыбы, столбы огня, молнии, трещины, шипы.
- Исправлено: после повторного старта герой больше не лежит мёртвым; Дьявол и некромант нормально ходят.

## Установка на Windows

- **[LandenSurvivors-Setup.exe](LandenSurvivors-Setup.exe)** — установщик. Можно выбрать папку, он создаст ярлык на рабочем столе. Удаляется через «Приложения» в параметрах Windows.
- **[LandenSurvivors-portable.exe](LandenSurvivors-portable.exe)** — работает без установки, например с флешки. При каждом запуске он сначала распаковывается, поэтому окно появляется секунд через 20.

Файлы около 124 МБ каждый, откройте файл и нажмите **Download raw file**. Нужна 64-битная Windows 10 или 11. Сборка не подписана сертификатом, поэтому SmartScreen может предупредить: «Подробнее → Выполнить в любом случае». При первом запуске Windows спросит доступ к сети: разрешите для частных сетей, иначе не будет мультиплеера. F11 — полный экран.

## Установка на Android

1. Скачайте [LandenSurvivors.apk](LandenSurvivors.apk) на телефон (кнопка **Download raw file** на странице файла).
2. Откройте файл и разрешите установку из этого источника, если Android спросит.
3. Запустите **Landen Survivors** — при первом запуске игра попросит придумать имя героя.

Нужен Android 6.0 или новее. Размер — около 29 МБ.

Это отладочная (debug) сборка: она подписана тестовым ключом, поэтому для Google Play не подходит. Если раньше была установлена сборка с другой подписью, сначала удалите её.

## Мультиплеер

- **Wi-Fi вместе с ПК:** ПК с exe и телефоны с приложением в одной сети видят игры друг друга в списке. С телефона без приложения можно открыть в браузере адрес, который ПК показывает в окне мультиплеера.
- **Wi-Fi:** телефоны в одной сети Wi-Fi (или друзья подключаются к точке доступа хоста). Один игрок нажимает «Мультиплеер → Создать игру», остальные видят игру в списке.
- **Bluetooth:** сначала сопрягите телефоны в настройках Android. На вкладке Bluetooth хост создаёт игру, остальные выбирают его телефон из списка.
